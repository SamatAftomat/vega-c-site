# Вега С — сайт

Одностраничный сайт для **«Вега С»** (ООО Вега С) — строительно-ремонтной
компании в Тольятти: ремонт помещений (косметический / евроремонт /
капитальный), строительство дач и коттеджей, промышленное и
административное строительство.

- Данные: карточка [2ГИС](https://2gis.ru/togliatti/firm/3096753024992550) —
  5,0 ★, 3 оценки, 2 отзыва, 44 фото, прайс из 3 позиций, рубрики, оплата
- Статический сайт: HTML + CSS + JS, без сборки
- Стиль: «Сигнальный чертёж» (Unbounded + Manrope) — как у сайтов 01–16
